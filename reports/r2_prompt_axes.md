# R2 模型向量图的两个轴：把 prompt 投上去看

**一句话结论：** PC1 不是「难 ↔ 易」，而是「强弱差距拉得开的 prompt ↔ 拉不开的 prompt」。低端是开放式咨询和推荐，高端是代码、逻辑题和带格式约束、有确定答案的题。PC2 才和难度相关，但它同时是语言轴：低端是简短的英文常识问答，高端是中文和日文的专业长任务。PC1 和评分 −0.76 相关，是因为强弱差距确实随 prompt 变化，而不是评分差项没吸收完平均实力。

## 1. 怎么做的
- **最终模型：** 用整个开发集训练的 R2（d = 128，学习率 1e-3，λ = 1e-5，14 轮），参数存在 `data/r2_final_params.npz`，和之前导出的向量完全一致。
- **prompt 在轴上的坐标：** 模型 m 在 prompt q 上「随 prompt 变化的适合度」等于模型白化向量和 prompt 白化向量的内积。把 prompt 白化向量投到图上同一个 PC 方向，得到 t1、t2。在全部 85,835 个开发集 prompt 上，t1、t2 的均值为 0、方差为 1，两者互不相关（相关系数 0.01）。
- **怎么读方向：** t1 高的 prompt 给 PC1 坐标高的模型加分。图上强档在 PC1 负端，所以 **t1 越低，强档越占优；t1 越高，强弱差距越小**。PC2 同理：t2 高的 prompt 对 Claude 4 系列、gemini-2.5-pro 有利，t2 低的对 llama-3.3、nova-pro、gemma 有利。
- **任务类型：** 用 Arena 原始数据自带的 LLM 标签（category_tag v0.1）：代码、数学、创意写作、指令遵循，以及 7 条「难度标准」（复杂度、创造性、领域知识、解题、真实场景、具体性、技术准确性）。按 Arena 的做法，满足 ≥ 6 条算「硬题」。这些标签是 Arena 用 LLM 打的，不是人工标注。
- **折外检验：** 训练集内的打分用的是模型见过的票，可能偏乐观。所以 5 个折各自只用 train 票训练同设置的模型，自己做 PCA，再给本折 eval 票打 t1。5 个折的 PC1 和最终模型 PC1 的模型坐标相关系数在 0.985 到 0.993 之间，说明这个轴很稳定。
- 只用开发集，测试集没有参与。

## 2. 两个轴的命名（Yiqing 2026-11-10 定：PC1 = 开放式咨询 ↔ 代码与确定答案题；PC2 = 简短常识 ↔ 专业难题，与语言高度重合）

| 轴 | 低端 | 高端 | 线程当时的建议 |
|---|---|---|---|
| PC1（65%） | 开放式咨询、推荐、学习路线（「怎么用 AI 赚钱」「推荐 3 本书」「从土耳其带什么回来」）。偏短，多语言，波兰语占 30% | 贴代码改 bug、写小程序、逻辑悖论、严格格式约束（「只答一个词」「答案放进 \boxed{}」）、游戏规则题。英文 85%，代码 53%，有很多长段代码粘贴 | **开放式咨询 ↔ 代码与确定答案题**（也可以叫「强弱差距拉开程度」） |
| PC2（16%） | 一句话英文常识问答（「新加坡总理是谁」「天是蓝的吗」）。英文 97%，长度中位 30 字符，硬题 2.5% | 中文和日文的专业长任务（HLS 加速器、电机控制代码、物理计算题）。中文 66%，日文 10%，数学 31%，硬题 75% | **简短英文常识 ↔ 中文专业难题** |

## 3. PC1 和评分 −0.76 相关：是哪种原因？

结论是**强弱差距随 prompt 变化**，不是评分差项没吸收完平均实力。证据有三条。

**1. 从模型结构看，PC1 装不下平均实力。** 投影前减掉了所有 prompt 的平均向量，所以在全部 prompt 上，t1 的均值是 0。也就是说，PC1 对每个模型的平均贡献都是 0。如果评分差项没吸收完平均实力，剩下的部分会落在每个模型的偏置 u 上。实际上，u 和评分的相关系数是 0.91，确实还剩一点。但 u 的幅度只有 −0.07 到 +0.05，大约相当于 ±10 分评分，说明平均实力绝大部分已经被评分差项吸收。

**2. 从数据看，强档的胜率随 t1 大幅变化。** 如果只是没吸收完的平均实力，各个五分位里强档的胜率应该差不多。实际情况如下（强弱档对战，折外打分）：

| t1 五分位 | 1（最低） | 2 | 3 | 4 | 5（最高） |
|---|---|---|---|---|---|
| 强档 赢 % | 75.0 | 67.9 | 60.0 | 55.9 | 50.4 |
| 平 % | 13.0 | 16.8 | 22.3 | 23.8 | 28.1 |
| 弱档 赢 % | 12.0 | 15.2 | 17.6 | 20.4 | 21.5 |
| 全部票：每 100 分评分差带来的质量分 | 0.17 | 0.14 | 0.11 | 0.10 | 0.08 |
| 全部票：平均评分差 | 73.3 | 72.2 | 71.8 | 72.1 | 71.2 |
| 硬题 % | 32.9 | 36.2 | 36.2 | 38.7 | 42.8 |

- 强档胜率从 75% 降到 50%，评分差的作用减半。各五分位的平均评分差都在 71 到 73 分之间，所以这个变化不是配对构成不同造成的。训练集内的版本是 77% 降到 49%，和折外几乎一样，所以也不是过拟合。
- **PC1 两端不是一端难、一端易。** 按 Arena 的硬题标签，五个分位从 33% 到 43%，变化很小，而且是强档优势小的那一端略难一些。

**3. 直观解释（推测，没有逐条核实）：** 开放式咨询题没有标准答案，投票取决于回答的知识面、结构和丰富程度，强模型的优势会被放大。代码、逻辑题和格式约束题有明确的对错，弱模型也经常能答对，或者两边都答错，所以平局多，差距小。PC1 和评分相关，是因为在「拉得开」的题上，额外的优势正好按实力排列。这就是「强弱差距随 prompt 变化」的含义。

**对路由的含义：** 开放式咨询值得发给强模型；代码题和有确定答案的题，发给便宜模型损失较小。另外，弱档里的 Claude 3.5 / 3.7 Sonnet 在 PC1 高端相对有利，这可能说明它们在代码题上的能力被 Arena 的总评分低估了。这一点只是推测。

## 4. PC2 补充
- PC2 和难度标准数的秩相关系数是 0.40（PC1 只有 0.04），所以真正的「难度轴」是 PC2。但在这份数据里，难题大多是中文和日文的专业题，难度和语言分不开。
- 强档胜率随 t2 只从 57% 升到 65%，影响比 PC1 小得多。PC2 主要区分的是哪类较弱模型吃亏：llama-3.3、nova-pro、gemma 这类模型在中文专业题上相对吃亏，在简短英文常识题上不吃亏。
