## 路由器与网格（都是三分类 赢 / 平 / 输，权重 1/n_votes）
| 名称 | 特征 | 超参网格（只在每折训练部分内按 80/20 选） |
|---|---|---|
| R3-LR | task_type 独热编码（8 类）+ 6 个分数的独热编码（每个 0–3）+ 评分差 + 模型身份 | C ∈ {0.01, 0.03, 0.1, 0.3, 1} |
| R3-MF | 结构同 R2，只是把 1024 维 prompt 向量换成上面的标签特征（38 维） | d ∈ {4, 8, 16}，λ ∈ {1e-5, 1e-4, 1e-3}，学习率 1e-3，早停 |
| R2-② | R2 原样，只用 ② 的票训练 | d ∈ {16, 64, 128}，λ ∈ {1e-6, 1e-5, 1e-4}，学习率 1e-3 |
| R2 + R3 | R2 的输入 = prompt 向量和标签特征拼起来（1062 维），只用 ② 的票 | 同 R2-② |

R3-LR 和 R3-MF 里，内层验证损失更低的那个作为「方案二」的代表，在每一折里分别选。

## 指标（和方案一一样）
- **主指标：** ② 强弱档按调用比例的 APGR，ΔAPGR 和评分差基线比；方案之间的差（R3 − R2-②，R2+R3 − R2-②）做配对 bootstrap，1000 次，按 prompt 组重采样。
- **次要指标：** 美元主案例的 APGR$、配对内 APGR$（下限）、CPT$(50%)。
- **Yiqing 加的分析：** 按 has_single_answer（0 / 1 / 2 / 3）分组，分别报各路由器的 APGR；is_open_ended 与方案一 PC1 坐标 t1 的秩相关（开发集）。

## 判定（事先说好）
- 方案二「有用」= R3 在 ② 的 ΔAPGR 区间不含 0。
- 方案二「比方案一好」= R3 − R2-② 的配对区间不含 0 且为正。
- 「组合有增益」= R2+R3 − R2-② 的配对区间不含 0 且为正。
